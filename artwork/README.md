# Artwork

Cin-MinAI's look (PLAN D17 rebrand, D38 "familiarity is a feature, our own aesthetics"). The branding
package (`distro/packages/cinminai-branding`) is built from the files here.

**Just made something? Put it in `incoming/`** — any format, any size, sketches included. The lead
sorts it into the folders below and makes the sizes each part of the system needs.

| Folder | What | Used for |
|---|---|---|
| `incoming/` | new work, unsorted | — |
| `logo/` | the logo: Ian's original + `logo.svg` (vector, **approved by Ian 2026-09-27**), built by `build_logo.py`; menu-button mark **A** (`mark-a.svg`, Ian's choice), built by `build_mark.py` | menu button, installer, welcome screen, about dialog, docs |
| `wallpapers/` | desktop backgrounds, vector (`generate.py`): **data-stream = the default** (Ian, 2026-09-27), circuit-floor and board as choices | default and extra backgrounds |
| `boot/` | boot splash (Plymouth), boot menu background | start-up and shut-down screens |
| `installer/` | installer slideshow slides | while the system installs |
| `colors.md` | the palette (hex values) and fonts | theme accents, sidebar, docs |
| `welcome/` | the welcome screen's texts (the designer's note) | first start after installing |
| `wallpapers/concepts/` | mood images (not shipped as they are) | the direction for wallpapers and theme |

Keep the **original files** (SVG, Krita/GIMP/Photoshop/Affinity files) next to the exports, so anyone
can change them later. Very large originals (over ~50 MB each) may need a different home — ask first.
